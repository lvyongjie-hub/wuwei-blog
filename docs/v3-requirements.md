# 五味书房 V3 需求基线

- 目标版本：`v3.0.0`
- V2 发布基线：`4aa52dd`（`release: publish v2`）
- V3 当前实现：`d9c7681`（`feat: add immersive homepage intro`）
- 确认日期：2026-07-29
- 状态：范围已确认，进入收尾验证

## 1. 版本目标

V3 定位为“五味书房”的品牌入口与体验升级版本。核心是已经实现的首页沉浸式工程序章，并完成性能、兼容性、SEO 和发布流程收尾。

V3 不以新增文章数量作为验收条件。书房文章、实验记录、项目证据和随笔在版本发布后继续通过 Markdown/MDX 或现有内容后台逐步补充。

## 2. 已确认范围

### 2.1 首页品牌序章

- 仅在首页进入时触发，不拦截文章、项目、实验、随笔和其他直达页面。
- 使用信号、工程图纸、索引卡和“五味”书票构成约 3.2 秒的品牌叙事。
- 每个浏览器会话默认播放一次，刷新页面不重复打断访问。
- 支持跳过、`Esc`、点击加速和首页书票主动重播。
- Three.js 按需加载，加载失败或超时后使用静态 SVG 降级。
- 移动端降低渲染负载，并保持书票与首页视觉位置连贯。
- `prefers-reduced-motion` 用户使用短暂静态序章，不播放完整动态过程。
- 序章素材全部由站点自身托管，不依赖外部 CDN、视频或音频。

### 2.2 体验与兼容性收尾

- 首页正文和导航不能依赖 WebGL 或序章脚本才能访问。
- WebGL 不可用、Three.js 加载失败或脚本超时时，页面仍能进入首页。
- 桌面和移动端不出现明显遮挡、横向溢出或无法跳过的状态。
- 键盘操作、焦点状态和减少动态效果偏好保持可用。
- 内容页面不加载首页 3D 场景代码。

### 2.3 性能边界

- Three.js 和场景代码继续采用首页按需加载，不进入全站公共首屏包。
- 3D 动态块 gzip 体积控制在约 160 KB 以内。
- 序章图片和矢量素材总量控制在 1.5 MB 以内。
- 不为了细微视觉提升继续增加大型模型、视频、音频或运行时框架。
- 动画完成、跳过或失败后及时停止渲染循环并释放不再需要的资源。

### 2.4 SEO 与发布配置

- 正式站点地址在 canonical、Open Graph、RSS、Sitemap 和 robots 配置中保持一致。
- 序章不改变首页可索引正文，不向搜索引擎输出只有动画的空页面。
- `main` 分支继续对应 Cloudflare Workers 正式站点。
- 正式发布前运行项目完整验证和 Wrangler 部署预检。

## 3. 明确延期

以下内容不属于 V3 验收条件：

- 新增书房文章、实验记录和随笔。
- 补充 STM32F407 项目的真实照片、波形或板级测试数据。
- 全文双语、Newsletter、账号、点赞或付费功能。
- 新增一级导航、复杂内容关联模型或独立数据库。
- Giscus、Analytics、CMS OAuth 和多角色权限系统。
- 更多 3D 场景、大型模型、粒子背景、自动音效或持续动画。

延期内容继续遵守既有需求基线中的真实性、脱敏和验证边界，不使用虚构内容填充空栏目。

## 4. 验收条件

V3 发布前应满足：

- 首页首次会话能够正常播放序章，并顺利过渡到现有首页。
- 刷新不重复播放，主动重播、跳过、`Esc` 和点击加速可用。
- 文章和项目直达页面不出现序章。
- 移动端、减少动态效果和 WebGL 降级路径可用。
- 浏览器控制台没有由序章产生的未处理错误。
- 内容路由不加载 Three.js 动态块。
- `npm run verify` 通过。
- `npx wrangler deploy --dry-run` 通过。
- 正式部署地址、GitHub 源码和 `main` 分支状态一致。

## 5. 发布清单

1. 完成桌面、移动端、减少动态效果和降级路径回归检查。
2. 检查序章资源体积、按需加载和渲染资源释放。
3. 检查 canonical、Open Graph、RSS、Sitemap 与正式地址。
4. 运行完整项目验证与 Cloudflare 部署预检。
5. 提交 V3 收尾改动。
6. 经确认后创建并推送 `v3.0.0` 标签。

## 6. 变更控制

V3 收尾阶段只修复影响上述验收条件的问题。任何新页面、新内容系统或新增大型视觉功能都进入后续版本，不在 V3 中临时扩展。
